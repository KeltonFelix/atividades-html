\## 🧠 O que pratiquei



\### HTML

\- Estrutura semântica (`header`, `main`, `fieldset`, `legend`, `label`)

\- Tipos de input: `text`, `email`, `password`, `date`, `file`, `tel`, `url`, `number`

\- Validação nativa: `required`, `pattern`, `maxlength`

\- Radio buttons, checkboxes e selects



\### CSS

\- Layout responsivo com `max-width` e centralização

\- `box-sizing: border-box`

\- Estilização de formulários

\- Grid Layout para checkboxes

\- Cores, sombras e bordas arredondadas
